# **App Name**: Binance Liquidator Bot

## Core Features:

- Real-time Market Data: Fetch and process real-time market data from Binance API to identify liquidation opportunities.
- Strategy Parameter Input: GUI allowing users to set parameters for trading strategies, such as risk level, order sizes, and liquidation price thresholds.
- Liquidation Opportunity Scanner: Analyze market data to identify potential liquidation events based on the strategy parameters.
- Automated Trading (Paper): Simulate buy/sell orders on Binance's paper trading platform based on identified liquidation events.
- Strategy Optimization Suggestions: Use generative AI to suggest parameter adjustments for strategies, based on the observation of the bot's tool of the live market data.
- Localhost GUI: Provide a local GUI (likely via a web browser) for monitoring bot activity, adjusting parameters, and reviewing performance reports.

## Style Guidelines:

- Primary color: Dark Blue (#24305E) to reflect stability and trust.
- Background color: Very dark gray (#121212) to focus the users attention.
- Accent color: Teal (#30D5C8) for calls to action and visual emphasis.
- Headline font: 'Space Grotesk', sans-serif, for a tech-oriented, modern look in headings and short text.
- Body font: 'Inter', sans-serif, for readability in reports and parameter descriptions.
- Use simple, geometric icons to represent different trading actions, parameters, and status indicators.
- Dashboard layout with clear sections for market data, parameter inputs, bot status, and performance reports.
- Subtle animations to indicate price changes, order execution, and alert notifications.
